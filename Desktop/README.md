# DeeraftApp Windows

基于 Prism Launcher 11.1.1 的 Windows x64 桌面应用。主界面已按确认的 Material 3 Expressive 设计实现为 Qt Quick/QML；Prism 仅用于相关二级窗口和启动核心。当前为内部测试版。

## 使用

推荐从[网站下载页](http://mc.ainfinitythecoder.cn/downloads/index.html)下载安装包。已有便携版请选择原文件夹安装，以保留 `data/` 中的账号和实例目录设置。安装、覆盖更新与卸载均保留应用数据；卸载只移除安装包提供的程序文件。社区账号和 Minecraft 账号独立，使用启动器不要求先登录社区。

便携 ZIP 仍可使用：解压完整文件夹后运行 `DeeraftApp.exe`，不要单独移动 EXE。数据默认保存在程序旁 `data/`。

0.6.2 恢复 Windows 原生窗口栏。有任务运行时，关闭窗口仍先确认；游戏运行中确认关闭只隐藏主窗口，不终止游戏。社区玩家动态最多显示两条。“设置 → 外观 → 颜色主题”使用一行分段色块选择，按钮底色对应各自配色，不显示自拟名称。配色会保存并同时用于浅色和深色模式。窗口、任务栏、安装包、二级窗口及下载页继续使用 D 标记。

“设置 → 应用更新”提供自动检查、手动检查、下载、取消和重启安装。自动检查每个安装每天最多一次，只读取静态小清单，不自动下载大文件。安装前检查签名与 SHA-256；游戏运行中不能执行更新。自动安装保留当前数据目录（包括 `--dir` 指定的目录），完成后重新打开应用。Prism 内核固定 11.1.1，不拉取上游 Prism 更新。

在“我的”中添加 Minecraft 账号，或在启动器账号菜单中进入账号管理。离线账号可直接创建、安装并启动原版；Microsoft 和第三方账号在应用内授权。Java 使用 Prism 的本机检测，也可在实例设置中手动选择；不自动下载 Java，不拦截 Java 版本兼容性，找不到本机 Java 时会提示选择路径。

“我的实例”内可分别筛选实例目录和分组；菜单中“添加实例目录”接受现有 `.minecraft`、`instances` 或包含这些文件夹的启动器目录。列表统一显示版本和加载器，不区分来源格式；底部和服务器实例选择器显示完整目录以区分同名实例。模组、世界、资源包、日志及实例设置共用 Prism 核心。自有适配信息放在便携数据目录的 `directory-instances/`，原游戏目录不会被转换，移除实例目录不删除游戏文件。同一游戏目录受运行锁保护；运行时关闭主窗口会最小化。

如果旧版本只声明继承其他启动器的全局设置，而所选目录不含全局配置，请在实例设置的“游戏目录”中明确选择实际文件夹。程序不会猜测共享存档路径。复制与导出的副本会清除原目录的绝对路径。

外部实例直接在原目录运行：沿用原游戏目录、共享 `libraries/`、`assets/`，以及原 Prism/MultiMC 的 `meta/` 和实例组件配置，不复制游戏资源到 DeeraftApp。普通启动按本地索引检查资源文件是否存在、大小是否匹配；依赖库校验后记录校验缓存，未变更时复用。资源齐全时跳过下载，缺失文件补到原目录；下载文件仍校验摘要。本地有效资源索引不会仅因上游语言文件更新而在每次启动时强制刷新。App 数据目录仅保存路径、适配配置和检查记录等；修改原组件配置前会备份到 `data/backups/directory-metadata/`。

实例目录导入、刷新和启动时的目录扫描在后台执行，模组/存档/截图列表按可见行创建，不会因大量存档一次性创建全部界面。选到文件、单个实例、空目录或损坏配置时会显示具体原因，不保存无效目录，也不清空已有实例列表。

社区与服务器页支持关联实例和服务器地址，“启动实例并加入”启动关联实例。第三方服务器配置仅保存在本地，并查询真实在线状态、版本和人数。社区聊天从社区页进入。

下载源提供自动、国内和官方模式；自动优先受支持的 BMCLAPI 地址，失败回退官方。登录认证不经过下载镜像。社区直播栏暂时只显示直播状态；KOOK 入口在接口没有邀请地址时打开 KOOK 网页版。

Fabric、Forge、NeoForge 与 Quilt Maven 按资源类型使用镜像，旧 Forge Maven 地址也受支持。镜像未覆盖的文件需要官方回退；网络或上游暂时不可用仍可能失败。自动模式的镜像与官方回退请求使用 15 秒无数据超时，后续重试重新考虑镜像。任务中心显示实际完成比例，失败任务位于“已结束任务”。启动内存不足改为应用内通知，不再阻断启动。

Minecraft 账号显示“正版登录”“离线登录”或可自定义的第三方站点名，头像来自对应 Minecraft 皮肤，尚未取得皮肤时显示占位头像。界面内置简体中文译文，首次离线打开二级窗口也可显示中文；二级窗口默认 Windows 11 主题和 WindowsApp 图标项。

## 开发

从仓库根目录执行：

```powershell
./Desktop/scripts/bootstrap.ps1
./Desktop/scripts/build.ps1 -Jobs 2
./Desktop/scripts/run.ps1
./Desktop/scripts/package.ps1
```

脚本只修改当前进程环境，不修改全局 PATH。工具链、缓存、构建和发行产物留在 `Desktop/`。可通过 `run.ps1 -AppArguments @('--dir','绝对路径')` 使用独立数据目录。并行链接占用内存较多，默认机器内存不足时使用 `-Jobs 2`。

- `app/`：QML 界面及 C++ 启动器、社区、账号、目录和下载源适配。
- `launcher/`：固定 Prism 源码，来源与许可证见 `UPSTREAM.md` 和 `LICENSE`。
- `backend/`：网站启动动态接口及部署、验证脚本。
- `design/m3-expressive/`：已确认的交互设计稿与素材来源。
- `docs/feature-matrix.md`：功能入口及实际验收边界。
