# DeeraftApp · M3 Expressive 设计稿

这是一份可离线打开的 HTML 交互设计稿，不是已经接入后端的桌面程序。账号、在线人数、版本、任务、聊天和统计均为设计展示数据；按钮只切换设计稿状态，不会登录、启动游戏、修改文件或执行服务器命令。

## 方向

**先选世界，再开始游戏。** 把实例选择与启动放在同一个桌面工作区，用清晰的色彩关系、醒目的主操作和短促的形状反馈表达 M3 Expressive。中文文案只保留对象、状态与动作。

不是手机界面的横向放大。导航改为桌面导航轨；启动器采用 list–detail，社区采用 supporting pane。游戏内容用真实 Minecraft 封面识别，文字与按钮不压在复杂图片上。

| 决策 | 本稿应用 |
| --- | --- |
| 桌面布局 | 96px 折叠导航轨，可展开；实例列表与详情并列；低于 1250px 收紧列表与间距 |
| 启动器主界面 | 实例选择、收藏/关联筛选、账号选择、启动、模组、世界、截图、日志全部使用 DeeraftApp 新界面 |
| Prism 边界 | 只有二级窗口复用 Prism。稿中的传统二级窗口仅示意边界，不是 Prism 对话框的精确复刻，也不代表其功能已经重新实现 |
| 配色 | 新的青绿色种子 `#216C5E`，使用官方 Material Color Utilities 0.3.0 生成角色色；与手机端主题配置无依赖 |
| 字体 | Roboto Flex 用于拉丁字母与数字，Noto Sans SC 用于中文；实例名使用强调字重，正文保持常规字重 |
| 形状 | 主要采用 12/16/20/28/32/48/full；连接按钮内侧小圆角、外侧全圆；文本密集区域不用抽象裁切 |
| 表面 | 导航、列表、内容使用 surface 角色区分；不把所有对象叠成阴影卡片，阴影主要用于菜单和模态层 |
| 图标 | 一套 Material Symbols Rounded；图标与文字共同说明导航；密集操作 20px 图标、40px 点击区 |

## 可体验的路径

- 启动器：切换实例、收藏、筛选关联目录、搜索、排序、查看模组/世界/截图/日志，体验准备启动与运行状态。
- 组件：连接按钮组按压形变、相邻按钮响应、拆分启动按钮、模组开关、波浪进度、可打断的下载侧栏弹簧。
- 社区：Minecraft 摘要、玩家、KOOK、直播间、进入启动器。
- 服务器：运行筛选、启停状态、控制台界面。
- 我的：累计游玩前五、每日在线、资料与游戏账号入口。
- 设置：浅色/深色、减少动态效果；按 Escape 关闭浮层。搜索支持 Ctrl K。

## 动效规格

物理参数来自官网公开 token 数据，`motion.js` 按单位质量积分；重新指定目标时保留速度。

| 类型 | damping ratio / stiffness | 使用位置 |
| --- | --- | --- |
| Fast spatial | 0.6 / 800 | 小按钮即时反馈 |
| Default spatial | 0.8 / 380 | 下载侧栏，支持途中反向关闭 |
| Slow spatial | 0.8 / 200 | 预留较大容器变化 |
| Fast / default / slow effects | 1 / 3800、1600、800 | 无回弹的颜色与透明度变化 |

CSS 形状变化使用官网提供的 Web 近似曲线；按钮为 fast spatial，导航轨展开为 default spatial。顶层页面先淡出再淡入；同一实例的内容标签横向移动、不叠加淡出。页面不会整体弹跳。减少动态效果时停用形变和弹簧。

## 原型与正式程序的差别

此交付不修改正式 App 的 UI。HTML 不调用 Prism、社区接口、文件系统或游戏进程。二级窗口预览只用于说明“主界面全新、二级内容复用”的设计边界。目录选择、认证与管理动作以入口及状态示意为主，后续实施须接入真实能力与权限校验。

封面是公开游戏截图，非服务器实景证明。玩家头像是本稿生成的 SVG 示例；正式版仍需使用网站相同的真实头像接口。来源与许可见 `SOURCES.md`。


## 批注修订

1. 导航不再切换 flex-direction、文字对齐或行高。图标与标签固定定位、标签宽度固定；展开只连续改变位置及导航宽度，添加按钮的文字淡入。72px 的行高保持不变，途中反向操作也从当前位置接续。
2. 主导航移除聊天。社区右侧的聊天条整行可点击，支持 Enter / Space；聊天页通过顶部返回社区，选中状态归属于社区。
3. 封面标签显示实例游玩时长，移除 Java Edition 的重复说明及下方重复时长。
4. 系统状态改为服务器页底部默认折叠入口，避免抢占服务器和个人快捷入口的位置。
5. 所有服务器均可关联实例。关联选择按实例目录分组；没有关联时，点击快捷加入先配置；已经运行时不重复启动，也不误把“服务器启停”当作“客户端启动”。
6. 第三方服务器有独立栏目，可新增、编辑、移除及关联实例。设计原型使用浏览器 localStorage；正式版使用便携数据目录中的个人配置，不上传到网站，不改原目录。
7. 搜索移入“我的实例”，Ctrl K 从其他页面转到启动器并聚焦搜索。使用 M3 的搜索容器、菜单选择与列表详情模式；目录与分组是可交叉的独立筛选，不用导航层级把它们混为一件事。
8. 玩家启动动态出现在社区右侧。实例从准备转为运行后追加动态，右下角显示 M3 inverse surface Snackbar，单一“查看”操作打开社区。这里只演示成功事件的 UI，不代表已经完成游戏进程或后端接入。

### 实例目录、分组与关联的正式数据规则

- 目录是来源：DeeraftApp、PCL、HMCL，允许同类型的多个目录。实例身份使用 `sourceId + canonicalInstanceId`，不能用显示名称或数组位置关联；重命名和同名实例不会造成串联。
- 分组是实例的组织方式，与目录正交。Prism 组保留原有成员；外部实例的分组另存在 DeeraftApp 个人配置，不覆盖 PCL/HMCL 未知字段。所有目录下可以按组筛选，也可以在某个目录里按组筛选。原型展示三个目录与三个现有组；创建/重命名组与真实扫描留给正式接入。
- 目录管理次级窗口展示来源类型、路径和实例数量。新关联目录后扫描只加入来源，不自动导入、移动或转换。移除关联默认保留游戏文件。
- 服务器关联保存 `{serverId, sourceId, instanceId}`。实例不存在时转为“未关联”，重新选择；版本不匹配时给出确认和配置入口，不静默启动错误版本。
- 快捷加入在启动前明确解析服务器地址，交给对应游戏版本支持的 quickPlay / server 参数；不把地址拼成 shell 命令。现有运行进程没有支持加入协议时提示在游戏内加入。

### 启动动态后端接入约定（待正式实施）

当前工作是 HTML 设计稿，本轮没有修改远程网站后端，也未向网站发送事件。

正式客户端仅在 Minecraft 进程确认创建后报告一次 `game.started`，不在点击按钮或准备阶段报告。社区账号通过现有会话鉴权；服务端从会话确定玩家身份，不信任客户端传入的用户 ID。事件由服务端生成时间并持久化，以客户端生成的 eventId 做用户范围去重。字段仅包含实例显示名称、游戏版本与事件标识；不包含本地路径、账号令牌、第三方服务器地址或启动参数。

现有动态/聊天实时通道新增独立类型 `game.started`，历史接口返回时间游标；客户端重连按游标补齐并去重。新事件出现在玩家动态并触发单个 Snackbar，不把启动动态混进 Minecraft 原始聊天。失败、取消、离线及未登录社区不伪造已发布记录；社区报告失败不阻断本地启动。历史补齐不批量弹通知。

本地个人服务器配置与社区动态完全分开；第三方地址始终留在个人数据目录。后端真实路由、数据库迁移和权限检查须在网站仓库中实施并联调，以上为可审查的接入约定，尚未声称实现。


## 第三方服务器状态与 Motion 补充

- 第三方服务器在列表内直接显示状态、服务端版本、在线人数 / 上限、延迟及更新时间，保留独立刷新按钮。状态有未检测、检测中、在线、离线、查询失败；未知人数用“—”，不当作 0，查询失败不当作离线。更改地址即失效旧状态；移除记录后忽略迟到响应。
- 状态属于短期运行信息，不写入个人服务器配置。正式客户端在本地用 Minecraft Java Server List Ping 查询，保留 SRV、协议/超时处理与缓存；不将个人服务器地址发送到网站后端。显示服务端返回的实际版本，关联实例版本不充当服务端版本。
- HTML 无法建立 Minecraft TCP 查询连接。本稿刷新仅演示“检测中→查询失败”，不把任意输入的服务器伪装成在线。`index.html?state=server-status` 展示在线、离线及失败三种设计数据，不表示真实查询；真实接入仍在原生客户端阶段。
- 实例目录和分组改为自绘 M3 filled select + 单选菜单。移除这两个选择器的系统原生弹出层；包含 tonal surface、标签、展开箭头、选中标记、来源路径、hover / focus state layer。支持 Enter / Space、方向键、Home / End、Escape、Tab、前缀检索与外部点击关闭，并将焦点归还触发器。
- 按最新批注，实例目录与分组菜单直接显示 / 收起，不再使用菜单弹簧、透明度动画或箭头过渡，筛选后的列表也直接更新。弹层复用启动菜单的表面色、20px 圆角、阴影、8px 内边距和 44px 选项行。
- 实例标签的指示条使用 fastSpatial 平移与变宽，替代原先瞬间换位。配置对话框用 defaultSpatial 进入，透明度用 fastEffects；状态反馈只短促淡入。沿用全局减少动态效果设置，正在进行的 Spring 在下一帧直接到目标值。

原文依据：[Motion physics — How it works](https://m3.material.io/styles/motion/overview/how-it-works)、[Menus guidelines](https://m3.material.io/components/menus/guidelines)。前者区分可回弹的 spatial 与不回弹的 effects，并按元素覆盖面积区分快 / 默认 / 慢；本稿使用已有官方 token 数值，不额外发明另一套参数。


### 下拉菜单层级修正

三点菜单的 z-index 高于整个 library-selectors 堆叠上下文；打开三点菜单会关闭目录与分组菜单，两个选择菜单也互斥。三点触发器停止 click 冒泡，避免尚在退出过渡中的弹层将快速重开误判成外部点击。已经检查明暗主题下三个菜单项中心点的实际命中元素，确认没有被选择器遮住。目录和分组的键盘操作仍保留。
