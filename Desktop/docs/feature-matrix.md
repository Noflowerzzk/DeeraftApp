# 功能实现与验收表

基线 Prism 11.1.1。以下区分代码入口与运行证据；保留核心不等于所有组合均已验证。

| 范围 | 实现与入口 | 运行验证 |
| --- | --- | --- |
| 主导航、主题、动效 | 原生 QML，社区/启动器/服务器/我的；聊天由社区进入；支持减少动效 | 原生明暗截图与设置窗口检查 |
| 实例新建、复制、导入、导出、删除、还原 | 实例菜单调用 Prism 二级窗口；主列表使用新界面 | 构建、实例加载通过；破坏性操作未对用户目录试验 |
| 分组、目录、收藏、搜索 | 目录与分组独立筛选；外部实例键包含目录 ID | 本地持久化和关联隔离测试通过 |
| 原版与加载器、整合包 | Prism 原创建/组件/平台窗口 | 离线账号原版 1.20.1 首次下载安装并启动成功，用户已确认；模组与各平台整合包待实机逐项验证 |
| 模组、世界、截图、日志 | 原生详情页读取；模组启停；资源/光影等复用二级窗口 | 构建通过，资源相关默认测试通过 |
| Java、内存、参数、环境、代理 | 新设置入口及原 Prism 高级设置 | 本地 Java 17 启动验证；其他组合待验证 |
| Microsoft 登录/刷新/皮肤 | 原 Prism 正版流程 | 等待用户应用内授权，不收集聊天凭据 |
| 离线账号 | 可直接添加；正常启动允许网络安装 | 首次安装和游戏启动已通过 |
| Authlib/Yggdrasil Connect | 独立账号适配、角色选择、刷新；原生账号界面入口 | 自动测试与编译通过；真实站点授权待用户完成 |
| PCL/HMCL | 原目录扫描、隔离、自定义目录、原生参数解析及启动 | 独立临时目录适配测试通过；未批量启动用户现有实例 |
| 第三方服务器 | 本地配置、实例关联、SLP/SRV 状态查询 | 本地 TCP 协议测试验证在线/版本/人数；关闭端口显示离线；保存失败不报成功 |
| 国内源和回退 | 按资源类型映射，保留下载摘要验证及官方回退 | 原生 ApiDownload 实际请求国内源后回退官方，SHA-1 一致；取消、损坏响应等全链路场景未全部验证 |
| 社区与聊天 | 真实 API、WebSocket、会话刷新、头像、KOOK、MOTD | 社区客户端自动测试通过；真实登录与长时会话仍需用户检验 |
| 启动动态 | 游戏进程启动后上报；社区显示并通知；服务端鉴权、幂等和游标 | 本地单元测试及生产环境 ASGI 检查通过，已重启启用，公网匿名请求 401 |
| 管理、上传、备份、恢复、日志、控制台、用户管理 | 原生页面和对话框；服务端权限验证 | 入口实现并编译；不同真实角色的写操作未做破坏性验收 |
| 直播 | 列表/配置 API 与 WebView2 独立播放器 | 编译通过；运行时和真实流播放待验证 |
| CLI、诊断、任务 | 保留 Prism CLI 与日志、任务；全局下载入口 | CLI 原版启动通过；默认测试通过 |
| 便携与更新 | 程序旁 data；禁止自动安装上游二进制；手动更新 | 开发机检查；Windows 10 和其他硬件待验收 |

测试和构建证据保存在本地 `Desktop/.cache/`，不随发行包分发账号或测试数据。符号链接提权测试保持禁用。
