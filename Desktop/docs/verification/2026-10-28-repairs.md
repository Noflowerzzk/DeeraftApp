# 2026-10-28 桌面修复验收

本轮按数据、实例核心、账号与系统集成、视觉交互排序处理。设计基于已确认的 HTML 稿；组件沿用 QmlMaterial，未重新拼装另一套主界面。

| 问题 | 修复与验证 |
| --- | --- |
| MOTD 长文本挤出内容 | 清除格式符及多余换行，限制两行并省略；摘要高度容纳按钮。长中英文混合文本截图验证按钮仍在容器内。 |
| 右上角持续加载 | GET 轮询不占全局前台操作计数。通过本地 HTTP 代理测试读取不显示全局加载、写入完成后停止加载。 |
| 运行中服务器为空 | 列表静态资料合并初始状态接口及实时状态；测试静态资料无 running 字段而实时状态为运行中，筛选保留一张服务器卡片。 |
| 直播空下拉 | 使用后端的 name、roomId 和 live_status；仅显示名称及直播状态，移除播放和编辑跳转。代理测试验证发送实际 roomId。 |
| KOOK 按钮灰色 | 无邀请地址时打开 KOOK 网页版。当前后端不提供频道邀请链接，因此不能承诺直接加入指定语音频道。 |
| 实例误报 Vanilla、资源功能禁用 | 加入统一 MinecraftInstance 适配，自有元数据保存在 data/directory-instances，资源仍使用原游戏路径。目录实例接入 Prism 组件、设置和任务。 |
| 外部实例目录 | 支持 .minecraft、Prism/MultiMC instances 及启动器父目录。统一称“实例目录”，不展示目录格式，不再有“已关联”筛选。 |
| 同名实例 | 服务器实例选择器显示名称及完整来源目录，实例页底部显示实际路径。键包含目录 ID，保持独立分组、收藏和配置。 |
| 模组、世界、复制及导出 | 独立中文目录测试识别 Fabric，读取一个模组与一个世界，完成模组禁用/启用；复制可排除模组并保留世界；副本清除绝对运行路径，原文件完整；ZIP 文件映射保持便携结构。 |
| 实例设置入口 | 齿轮直接打开 Prism 实例设置页；增加统一“游戏目录”页签，处理旧配置无法推断全局目录的情况。 |
| 账号名称与头像 | msa 显示“正版登录”；第三方账号可编辑站点显示名称。菜单键使用内部账号 ID，避免不同提供方同 UUID 冲突；头像来自对应 Minecraft 皮肤，缺失时显示中性占位头像。 |
| 任务栏图标及旧上边栏 | 主窗口成为独立 Qt::Window，安装多尺寸窗口图标。运行检查确认无父窗口、有图标、主窗口没有 Prism 工具栏。 |
| 默认图标与二级窗口 | WindowsApp 图标项使用内置彩色图标资源；二级窗口采用 Windows 11 Qt 样式。 |
| 英文日期与二级窗口 | 随包内置官方简体中文翻译及日期/通用按钮补充。支持无在线索引时加载本地 QM；日期弹窗中文按钮、居中位置及中文实例设置截图检查。 |
| 菜单层级、位置及 hover | 菜单置于全窗口浮层，限制可用高度；菜单项填满可用宽度并使用统一状态层圆角。修正 Qt 曲线渲染导致页面往返后填充消失的问题，截图像素检查确认两个下拉背景均保留。 |
| 选中态、结束按钮及小动效 | 实例选中背景使用 tonal 背景色，减少动态效果设置继续生效；加入组件弹簧圆角和按压反馈；结束按钮两段均为 error 红色。 |
| 下载进度 | 使用 QmlMaterial 波浪进度组件。修复嵌入 QQuickView 中进度值动画未推进的问题，改用 Qt 统一动画时钟；测试数值与显示位置均为 0.37，波幅展开并继续移动。 |

## 验证方法

- `Desktop/scripts/verify-repairs.ps1`：每次创建全新的测试数据、源游戏目录和截图目录，只使用虚拟账号及测试内容。检查布局、中文日期、运行状态、目录核心、模组启停、复制、导出、设置入口和波浪进度。
- Release CTest：23 个启用项通过；会触发符号链接提权的 FileSystem 测试保持禁用。
- 社区客户端测试通过，包含本次新增的加载状态与直播字段回归测试。
- 实际目录只读扫描：HMCL 49 个版本、Prism/MultiMC 16 个实例；例如 1.16fsg 为 Minecraft 1.16.1 / Fabric 0.16.14，1.19.1-OptiFine 识别为 OptiFine。未改写这些样例目录，也未读取其账号凭据。
- 日志检查无 QML ReferenceError、TypeError、绑定循环或 polish 循环。

有一个旧 HMCL 版本只声明继承全局设置，而提供的 .minecraft 目录不含该配置；用户需要在“游戏目录”中明确选择路径。未批量启动真实整合包或修改用户存档。真实第三方皮肤服务、正版刷新和第三方授权仍需用户在应用内验收；Windows 10 实机尚未覆盖。

交互参考：[Material 3 transitions](https://m3.material.io/styles/motion/transitions/transition-patterns)。本轮截图及机器检查结果放在同名 `2026-10-28-repairs/` 子目录；它们使用测试数据，不能视为真实游戏运行或直播播放证明。
