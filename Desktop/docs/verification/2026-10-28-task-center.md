# 任务中心、缓存复用与菜单修正 · 2026-10-28

沿用批准的 M3 Expressive 桌面布局、绿色角色色、QmlMaterial 组件及减少动态效果设置。本轮只调整任务反馈、菜单交互和导入资源检查。

## 实现

- “下载任务”改为“任务中心”。启动检查与准备进入同一侧栏；下载、上传、实例目录扫描、社区操作和运行中的实例使用对应图标。收到实际进度信号后才显示进度及百分比，不将 Prism 任务基类默认的总量 100 当作已知总量；没有总量时显示动态波浪线。运行实例提供红色结束按钮。请求 URL 收进悬停详情，主要状态显示当前阶段。
- 移除右上角没有任务说明的常驻加载形状，保留任务中心入口和进行中数量。社区 WebSocket 对有效期内令牌的策略拒绝不再反复触发刷新令牌 POST；正常失效刷新和断线重连保留。
- 实例菜单删除两个始终隐藏但占高度的项目，首项为“编辑实例”。原有 Java 和运行目录设置仍可从实例设置打开。
- 下拉菜单的鼠标高亮不再触发滚动定位；仅键盘导航主动把高亮项移入视野。条目与状态背景使用菜单可用宽度，长路径居中省略，悬停提供完整文字。快速移开鼠标后即时清除非选中行的 hover 填充，保留选中和按压形变。

## 为什么导入后还下载

原适配器导入了实例元数据，却没有复用原启动器共享的 `libraries/`、`assets/`；此外，上游启动流程每次把资源索引标为过期，镜像日志又在缓存检查之前打印。因此既存在真正的重复下载，也存在仅检查缓存却打印镜像地址的误导日志。

现在在启动准备中异步校验 DeeraftApp 缓存，再检查来源目录。完整文件通过本地复制复用到便携缓存；只有缺失或校验失败的内容交给原下载流程。已有摘要使用 SHA-1，无摘要 JAR 检查 ZIP/CRC，旧版无摘要索引检查 JSON 结构；资源对象按索引摘要验证，大小相同的损坏文件也会补齐。取消在流式读取与复制过程中生效。

来源游戏文件保持只读；使用独立文件复制，不创建硬链接。首次复用可能需要本地磁盘复制，这不属于网络下载。版本元数据、账号刷新、实际缺失的依赖或主动安装新内容仍可能联网；没有把所有联网请求一律禁止。Prism 目录的共享缓存按标准的 `instances/` 同级位置查找。

## 验证范围

- 独立临时目录验证首次复用、再次复用零复制、摘要命中后缓存请求直接成功、同大小损坏资源补齐、无摘要 JAR 的 CRC、旧版索引和取消；不修改用户实例。
- 24 项启用的根 CTest 检查通过；上游 FileSystem 测试仍为禁用状态。社区独立测试通过，包括本地 WebSocket 返回 1008 时有效期内令牌不会触发持续刷新。
- 原生鼠标、滚轮、键盘检查菜单首项与宽度、滚动稳定性、快速 hover、运行实例波浪指示和真实本地 HTTP 请求取消；模组开关、头图、社区滚动、侧栏过渡继续回归。
- 实际 MultiMC 样例导入 16 个实例，3798 个存档仅实现可见行；两次导入检查后原始 32 个元数据文件摘要不变。

Qt 截图来自实际程序。当前会话的窗口未向真实桌面曝光，使用显式渲染帧和 Qt 原生输入事件检查；菜单及关联对话框的几何取证关闭了测试状态的进出场动画，正式程序的菜单动效保留。任务侧栏仍验证中间位置及波浪状态。这不等同于真人在前台窗口观察动画。没有在本轮使用用户的正版或第三方账号启动真实游戏，也未声称完成所有版本的零网络启动验收。
