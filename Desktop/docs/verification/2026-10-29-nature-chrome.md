# Nature 配色、一体标题栏与关闭确认 · 2026-10-29

沿用已确认的 Material 3 Expressive 界面。主动作保持“选择实例并启动”；标题栏退居次要层级，主题入口放在既有设置中。

## 实现

- 玩家动态只显示最近两条。
- Nature 是本应用的自然色主题组：森林、苔原、湖泊、陶土、石楠；不是另造颜色角色。选定种子后由 QmlMaterial 的 Material 色彩生成器产生完整浅色/深色角色，页面、菜单、按钮、任务中心和弹窗共用一套颜色。选择写入 desktop.ini，非法值拒绝。
- 沿用 HTML 设计稿的 D 标记，制作多尺寸 PNG/ICO；替换窗口/任务栏、主 EXE、安装器、卸载器、关于页、二级窗口和下载页图标。附可重复生成脚本与逐像素校验 EXE 图标的脚本。实例图标、玩家头像保留各自含义。
- 一体化 QML 标题栏提供拖动、双击最大化、最小化、还原和关闭。边缘可调整大小；Windows 保留原生缩放/吸附框架与阴影，最大化采用当前显示器工作区。
- 系统关闭与标题栏关闭共用确认逻辑，活动任务先询问；确认里列出最多三项当前任务。取消继续运行；游戏运行中确认关闭只隐藏主窗口，保留原有游戏后台生命周期。
- 标题栏按键复用 Expressive 弹簧点击反馈，确认弹窗复用现有统一过渡，遵循减少动态效果。
