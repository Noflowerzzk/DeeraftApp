# DeeraftApp 0.6.2 · Windows x64

适用于 Windows 10 / 11 x64。Prism 启动核心固定为 **11.1.1**。

## 本次更新

- 恢复 Windows 原生窗口栏。
- 配色选择改为连体分段色块，各自显示对应底色；移除自拟颜色名称。
- 修复任务栏身份与图标引用，安装时更新快捷方式图标并通知 Windows 刷新。
- 保留运行中任务的关闭确认、两条玩家动态及现有启动器功能。

## 下载与使用

- **setup.exe**：安装包。已有便携版请安装到原程序目录，以保留 `data/` 中的账号与设置。
- **portable.zip**：解压完整目录后运行 `DeeraftApp.exe`，不要只移动 EXE。
- **SHA256SUMS.txt**：安装包与便携版的 SHA-256 校验值。

安装后可在“设置 → 应用更新”中检查更新。更新会保留数据，Prism 内核不自动更新。

国内下载入口：[网站下载页](http://mc.ainfinitythecoder.cn/downloads/index.html)。

## 验证

24 项启用的测试通过，专项 Qt 检查连续三轮通过；安装、覆盖更新、卸载及签名更新通道已验证。Windows 任务栏进程/窗口标识和图标资源通过实际 API 读回检查。

源码包含上游 Prism 及许可证；构建方法见仓库内 `Desktop/README.md` 与 `Desktop/release/README.md`。
