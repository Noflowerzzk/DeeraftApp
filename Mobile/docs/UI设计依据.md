# UI 设计依据

参考：[Kole Jain / Mobile App UI](https://www.kolejain.com/resources?scrollTo=mobile-app-ui)。

本项目没有仅凭截图复制界面。先抓取页面 HTML，检查 `mobile-app-ui` 区块与 Svelte 内嵌资源数据，获得原始 Figma 链接、`.fig` 下载位置和预览资源列表；随后读取 `.fig` ZIP 中 `canvas.fig` 的结构化部分，解析 Kiwi schema，并解压 Zstandard 消息，得到 2,588 个节点。

可复核的提取结果见 [ui-reference-data.json](ui-reference-data.json)。原始 HTML、CSS、Canvas 二进制和解码后的完整节点保存在本地 `work/`，不提交第三方完整设计文件。

从设计节点确认的参数：

| 项目 | 源数据 | App 使用方式 |
|---|---|---|
| 基准画板 | 393 × 852 | 适配手机宽度，不绘制手机外壳 |
| 页面 / 卡片背景 | `#141414` / `#1F1F1F` | 深色界面层级 |
| 次级表面 | `#242424` | 按钮、输入框等 |
| 强调色 | `#2995FF`、`#FFDD55`、`#7373FF`、`#FF8573` | 操作、提示与分类 |
| 字体 | DM Sans，章节标题 18、正文 16、导航标签 10 | 捆绑开源 DM Sans，中文回退 Noto Sans SC |
| 常见卡片圆角 | 16 | 内容卡片 |
| 常见间距 | 4、8、12、16、24 | 页面与列表布局 |
| 导航 | 浮动胶囊，满圆角，半透明表面 | 四个实际功能入口 |

画板的 47 圆角是手机展示外壳，不用作 App 内容圆角。App 新增的在线绿色、玩家首字母头像、MC 方块插画、中文页面文案属于功能适配，不声称来自原设计。动画时长是实现选择，静态设计数据不能证明原交互时长。

字体随包离线加载，不依赖运行时网络下载。字体授权文件位于 `assets/fonts/`。

## v0.3.0 动效与组件

继续使用上方已解析的 Figma 配色、字体、圆角和紧凑浮动导航。动效参考 [Material Motion 的标准与表达方案](https://m3.material.io/styles/motion/overview/how-it-works)，本应用选择幅度较小、不过度回弹的交互；时长和曲线是本项目的实现参数，不声称是原设计文件或 Material 的官方 token。

| 用途 | 实现 |
|---|---|
| 按压与颜色反馈 | 140ms，缩放至 97.5%，不截获子控件的点击或滚动 |
| 页面切换、底栏选中背景滑动 | 260ms，小幅位移淡入；页面保持挂载，保留滚动位置与展开状态 |
| 卡片和新消息入场 | 380ms，最多位移 10px，只在首次挂载时执行，不随定时刷新重复播放 |
| 玩家列表展开、卡片内容变化 | 统一 260ms 尺寸过渡 |
| 数字变化 | 轻微滑动淡入，等宽数字避免宽度抖动 |

渐变、细描边与局部毛玻璃仅用于现有深色表面和底部导航，没有增加装饰文案、标题箭头或连接设置。没有常驻循环动画；刷新等待时显示进度指示。

自定义动效遵循 [Flutter `disableAnimations` 的适配说明](https://api.flutter.dev/flutter/widgets/MediaQueryData/disableAnimations.html)：Android 开启“移除动画”时，按压缩放、位移与过渡直接完成。交互功能保持可用。

## v0.3.1：恢复原有表面样式

按用户反馈，撤回 v0.3.0 新增的卡片渐变、彩色/灰色描边、底栏渐变、阴影、选中项内描边、筛选开关描边及自定义弹层表面主题。卡片恢复纯色 `#1F1F1F` 和原有 16 圆角，底栏恢复原本的单色半透明样式。原先已有的导航外边框和按钮样式保留。

v0.3.0 的切页、导航滑动、按压、卡片入场/展开、数字和消息动画，以及页面状态保留、减少动画适配均保持不变。

## v0.4.0：Material 3 全面改版

当前界面已按用户要求改为 Google Material 3，使用标准组件、种子色生成的深浅主题和统一动效。新的 [Material 设计说明](Material设计说明.md) 为当前设计依据；上方 Kole Jain 与 v0.3.x 内容保留为历史记录。
