# UI 设计依据

参考：[Kole Jain / Mobile App UI](https://www.kolejain.com/resources?scrollTo=mobile-app-ui)。

本项目没有仅凭截图复制界面。先抓取页面 HTML，检查 `mobile-app-ui` 区块与 Svelte 内嵌资源数据，获得原始 Figma 链接、`.fig` 下载位置和预览资源列表；随后读取 `.fig` ZIP 中 `canvas.fig` 的结构化部分，解析 Kiwi schema，并解压 Zstandard 消息，得到 2,588 个节点。

可复核的提取结果见 [ui-reference-data.json](ui-reference-data.json)。原始 HTML、CSS、Canvas 二进制和解码后的完整节点保存在本地 `work/`，不提交第三方完整设计文件。

从设计节点确认的参数：

| 项目 | 源数据 | App 使用方式 |
|---|---|---|
| 基准画板 | 393 × 852 | 适配手机宽度，不绘制手机外壳 |
| 页面 / 卡片背景 | `#141414` / `#1F1F1F` | 深色界面层级 |
| 次级表面 | `#242424` | 按钮、输入框等 |
| 强调色 | `#2995FF`、`#FFDD55`、`#7373FF`、`#FF8573` | 操作、提示与分类 |
| 字体 | DM Sans，章节标题 18、正文 16、导航标签 10 | 捆绑开源 DM Sans，中文回退 Noto Sans SC |
| 常见卡片圆角 | 16 | 内容卡片 |
| 常见间距 | 4、8、12、16、24 | 页面与列表布局 |
| 导航 | 浮动胶囊，满圆角，半透明表面 | 四个实际功能入口 |

画板的 47 圆角是手机展示外壳，不用作 App 内容圆角。App 新增的在线绿色、玩家首字母头像、MC 方块插画、中文页面文案属于功能适配，不声称来自原设计。150–200ms 切换动画是实现选择，静态设计数据不能证明原交互时长。

字体随包离线加载，不依赖运行时网络下载。字体授权文件位于 `assets/fonts/`。
