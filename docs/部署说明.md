## 安装与更新

```bash
cd /home/ainfinity/DeeraftApp-staging/server
python3 install.py                 # 检查，不修改业务文件
python3 install.py --apply         # 校验基线，备份后安装
python3 configure.py              # 首次生成私有配置；已有文件不覆盖
```

`changes.patch` 用于审阅。`baseline.json` 保存安装前业务文件的哈希；如果文件已被其他操作修改，安装器会停止，需要先重新核对补丁。不要通过重置远程 Git 来绕过检查。

新增模块修改可直接更新补丁包；修改现有业务文件时，需要重新生成其基线和差异。安装器不自动重启进程。

首次安装后进行了兼容性检查，并重启网站后端和 QQ_bot。原 `run.py` 开启了 `reload=True`，重载子进程曾占用 8000 端口；当前改用同一 Conda Python 运行 `uvicorn main:app`，不启用开发重载。`run.py` 源文件保持原样。MC 进程没有停止或重启。

```bash
python3 restart_services.py --backend --bot
```

该脚本仅查找已知工作目录中的服务进程，保留原进程环境；若发现多个候选会停止，不会猜测性终止进程。后台日志位于私有配置目录的 `backend.log`、`bot.log`；机器人运行于 `screen` 的 `bot` 会话。

## Microsoft 登录

当前服务器尚未配置 Microsoft OAuth，网站原配置的前端与回调地址仍为 `localhost:5173`。需在现有配置中设置客户端 ID、Secret、对外回调 URI，并与 Microsoft 应用注册一致，才能验证真实授权。

移动端复用已有 `/api/v1/auth/microsoft/callback`，以单独的 `mobile.` state 区分网页流程。回到 App 的 URL 只含 60 秒有效的一次性交换码，交换时必须提供对应的 PKCE verifier。网页登录回调行为保持原样。

## 运行边界

App 默认连接现有 HTTP 网站；未修改公网反向代理或 TLS 配置。首版没有通知、服务器控制或机器人管理接口。真人名单只用于区分真人与机器人，不修改入服资格。
